The work ranges from compact mobile arcade games to application prototypes and real-time graphics tools. Unity is the main game engine, supported by Android, web, and WebGL development when an idea needs a different surface.

The build loop

From rough idea
to readable game.

The process stays deliberately small and playable at every stage, so each decision can be tested in the thing itself.

01

Find the hook

Reduce the concept to one interaction that is easy to explain and quick to test.

02

Prototype the loop

Validate movement, timing, and feedback before adding production weight.

03

Create the language

Use color, sound, motion, and interface states to make the rules visible.

04

Refine by playing

Remove friction and keep only the elements that make the core idea stronger.
