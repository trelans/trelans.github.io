# Trelans

An anonymous static portfolio for independent game projects and browser-based graphics experiments.

## Site sections

- `index.html` — home, featured work, and interactive lab
- `works.html` — filterable project archive
- `about.html` — project-focused practice and process
- project HTML files — individual case studies powered by `js/projects.js`
- `paint.html`, `figure.html`, and `breather.html` — interactive WebGL demos

The site uses plain HTML, CSS, and JavaScript and can be previewed with any local static-file server.
